# 曾以结婚移民（F-6）身份在韩国居留的配偶再次申请F-6-1签证时 — 同一配偶且婚姻未中断时适用的简化材料清单

如果外国配偶过去曾以结婚移民（F-6）身份在韩国生活，且与同一韩国配偶的婚姻至今从未中断，那么再次申请韩国国民配偶（F-6-1）签证时，可以使用"过去曾以结婚移民（F-6）身份在韩国居留的情况"材料清单。所需材料比一般清单少很多，但如果配偶已变更，或即使是同一配偶但婚姻曾经中断，则不适用此清单。

本文面向过去持F-6在韩国生活、出境后希望与同一配偶再次入境韩国的夫妇。

## 要点摘要

- 对象：外国配偶过去曾以结婚移民（F-6）身份在韩国居留（不论长期或短期）
- 排除：配偶已变更，或即使是同一配偶但婚姻曾中断
- 简化清单：基本材料、邀请函与身份担保书、韩国配偶的证明书、外国配偶的材料、住房要件材料、交往证明的共同必备材料
- 清单中没有的：结婚背景陈述书、收入要件材料、沟通（韩语）材料、按认识经过区分的材料
- 国际婚姻指导项目对象国家（中国、越南、菲律宾、柬埔寨、蒙古、乌兹别克斯坦、泰国）与其他国家的简化清单构成相同
- 签发签证：居留期间90天以下的单次签证，入境后90天内办理外国人登录及延长居留期间

## 1. 谁可以使用这份简化清单？

标准是"外国配偶过去曾以结婚移民（F-6）身份在韩国居留"。收入要件、沟通要件、介绍经过材料的免除规定都附有相同条件，其中沟通要件和介绍经过的免除规定写明不论居留是长期还是短期。

但所有规定都附有同样的但书：配偶已变更，或即使是同一配偶但婚姻曾中断的，予以排除。婚姻中介材料的免除文字也表述为"过去婚姻未中断、与同一国民"居留的情况。也就是说，与同一韩国配偶的婚姻必须从开始一直延续到现在。

## 2. 简化材料清单全文

| 区分 | 材料 |
|---|---|
| 基本材料 | 申请书、护照用照片、申请人（外国配偶）护照原件及复印件1份、申请手续费 |
| 填写材料 | 外国配偶邀请函、身份担保书 |
| 韩国配偶 | 护照复印件1份、基本证明书（详细）1份、婚姻关系证明书（详细）1份、家庭关系证明书（详细）1份、居民登记誊本（韩文原件）1份 |
| 外国配偶 | 本国结婚证明书（仅限需要时）1份、结核相关诊断书（仅限结核高风险国家）1份、其他特别适用于该国的材料（例：菲律宾CFO教育结业证原件及复印件1份） |
| 住房要件 | 自有住房：房产登记簿誊本 / 租赁住房：房产登记簿誊本、租赁合同复印件1份 |
| 交往证明材料 | 共同必备材料 |

交往证明的共同必备材料是能证明交往经过和婚姻真实性的材料，可将交往照片、家庭照片、SNS聊天记录等自由编排在A4纸上提交（5页以内）。本国结婚证明书是选择性材料，仅在需要确认本国是否重婚等情况时才要求提交。

## 3. 与一般清单相比少了什么？

与一般清单相比，简化清单中不包括以下材料：

- 外国配偶的结婚背景陈述书
- 韩国配偶的收入要件相关材料（所得金额证明、信用信息查询书等）
- 外国配偶的沟通要件相关材料（韩语相关材料等）
- 按认识经过区分的材料（婚姻中介机构登记证复印件、保证保险单复印件、合同复印件；介绍人身份证复印件）

此外，国际婚姻指导项目对象国家一般清单中的国际婚姻指导项目结业证、韩国配偶健康诊断书、外国配偶犯罪经历证明书和健康诊断书，在简化清单中也没有列出。不过，提交材料在受理和审查过程中可能有所增减，实际可以省略哪些材料，应以申请所在驻外使领馆的说明为准，并需根据个案确认。

## 4. 国际婚姻指导项目对象国家与其他国家有何不同？

国际婚姻指导项目的对象是以结婚同居为目的、邀请法务部长官公告的特定国家国民的人，特定国家为中国、越南、菲律宾、柬埔寨、蒙古、乌兹别克斯坦、泰国。提交材料也分为"国际婚姻指导项目对象国家"和"对象国家以外"，只有对象国家的一般清单中有国际婚姻指导项目结业证一项。

但"过去曾以结婚移民（F-6）身份在韩国居留的情况"清单在两类国家中都由相同材料构成，并附有相同的但书（配偶变更或婚姻中断时不适用）。随国家类别不同的是一般清单；如不符合简化条件，则须按所属国家类别的一般清单准备。

## 5. 配偶已变更或婚姻曾中断时

此时不适用简化清单，也不能以过去的F-6居留作为收入要件、沟通要件、介绍经过材料的免除理由。例如，过去与另一位韩国人结婚并持F-6居留、现在与新配偶再次申请的情况，或与同一人离婚后复婚的情况，都需要准备完整的一般清单。

如果夫妻之间有所生子女，另有"夫妻之间有所生子女的情况"清单，但该清单包括结婚背景陈述书和子女名义的家庭关系证明书（详细）。可以使用哪份清单因婚姻经历而异，需根据个案确认。

## 6. 准备材料时的注意事项

- 有效期：除另有规定外，邀请函及婚姻关系证明书等提交材料须在填写日或签发日起3个月以内。
- 韩国配偶证明书：基本证明书、婚姻关系证明书、家庭关系证明书须为"详细"版，居民登记誊本须为韩文原件。
- 地址一致：为满足住房要件所提交住所的地址须与居民登记誊本上的地址相同。
- 护照：一般清单备注栏写明申请人护照原件的剩余有效期须在6个月以上。
- 补充材料：个别审查过程中可能要求提交规定材料以外的补充材料。
- 入境后：F-6-1签证签发为居留期间90天以下的单次签证（美国人为多次签证），入境后须在90天内办理外国人登录并延长居留期间。

## 7. 常见问题

- 与同一人离婚后复婚，却视为"同一配偶"而按简化清单准备
- 仅凭过去的F-6居留经历，在配偶已变更的情况下仍省略收入、韩语材料
- 外国配偶是结核高风险国家国民却漏交结核相关诊断书
- 证明书开具过早，申请时已超过签发日起3个月

## 常见问题

### 以前持F-6居留的时间很短，也能使用简化清单吗？

沟通要件和介绍经过材料的免除规定写明不论居留是长期还是短期。但必须是同一配偶，且婚姻从未中断。

### 我们离婚后又与对方复婚了，适用吗？

规定写明即使是同一配偶，婚姻曾中断的也予以排除，因此不属于简化清单对象。需要准备一般清单。

### 可以不提交结婚背景陈述书吗？

简化清单的填写材料栏中只列有外国配偶邀请函和身份担保书，没有结婚背景陈述书。驻外使领馆在审查过程中仍可能另行要求。

### 在韩国国内变更为F-6-1居留资格时也是同一份清单吗？

韩国国民配偶（F-6-1）居留资格变更许可的提交材料准用F-6-1签证签发时的提交材料，受理和审查过程中部分材料可能有所增减。能否变更本身取决于目前的居留资格，需根据个案确认。
